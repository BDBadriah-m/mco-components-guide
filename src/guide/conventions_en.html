Before you start

Shared build rules

The theme MCO_OutSystems_Theme.css is installed in the MCO_Theme module, and the Blocks are built in the MCO_Components module. All styling lives in the theme, so no Block needs CSS of its own.

ExtraClass: every Block has a Text Input Parameter named ExtraClass that's added to the root class, for screen-specific adjustments.

Colors and spacing: don't write fixed values in Style Properties. Use the theme classes or semantic variables such as var(--color-text-brand) and its siblings.

Direction (Arabic and English): components follow the page direction. Arabic: OutSystems adds is-rtl to body, so it becomes RTL. English: without the class it's LTR, and spacing, arrows and the stepper flip automatically. Don't add dir to inner elements. Fixed text inside the Blocks (“View details”, “Collapse menu”…) is translated through OutSystems Multilingual or becomes Input Parameters. Try any component with the “عربي / EN” button next to its title.

Dark mode: data-theme="dark" on <html> itself. Without it the interface is always light (the default), and the device's dark setting doesn't change it.
